# 디딤돌 상단 UI 개선 패치

## 변경 내용
- 상단 메뉴에서 **Prompt Coach 제거**
- 메뉴 수를 줄이고 오른쪽 액션 영역(마이페이지, 로그인/로그아웃) 분리
- 버튼 간격과 스타일 정리로 가독성 개선
- Streamlit 상단 `Share` 툴바 숨김
- 홈 화면 원본 HTML 렌더링에서도 `Prompt Coach` 문구 제거 또는 자연스럽게 교체

## 업로드할 파일
- `app.py`
- `friend_pages.py`
- `ui.css`

## 적용 위치
기존 프로젝트에서 이 세 파일이 있는 같은 폴더에 덮어쓰면 됩니다.
