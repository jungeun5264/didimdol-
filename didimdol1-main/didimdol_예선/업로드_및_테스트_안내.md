# 디딤돌 2.0 | 실전 미션 25개 확장 (4단계)

## 무엇을 바꾸는가
- 기존 6개 미션과 ID는 그대로 유지합니다.
- `missions.py`에 새로운 19개 미션을 추가했습니다. 5개 분야(일상·학업·취업·실전직무·평가) 각각 5개씩 총 25개입니다.
- 추가 미션마다 제목, 상황, 3가지 목표, 제약조건, 4가지 최종안 입력 항목, AI가 생성할 상황의 대비용 변수 3개, 주요 평가 역량을 정의합니다.
- `training.py`, `luna_service.py`, `app.py`, 회원가입/DB/LPA 코드에는 손대지 않았습니다. 기존 화면은 미션 데이터를 반복해서 그리므로 25개를 자동 표시합니다.

## GitHub 업로드
1. 기존 `missions.py`가 있는 폴더와 같은 위치에 이 ZIP에서 `missions.py`만 업로드하세요. 기존 파일을 교체합니다.
2. `verify_missions_25.py`는 선택 사항이며 같은 폴더에 넣으면 별도 테스트할 수 있습니다.
3. `python verify_missions_25.py`로 데이터 무결성을 검증합니다.
4. GitHub `main`에 바로 반영하지 말고 테스트 브랜치에서 변경·실행하는 것이 안전합니다.

## 테스트 계획
- 실전 훈련 목록에 전체 25개, 범주별 5개가 보이는지 확인.
- 기존 미션 `travel` 1개와 새 미션 `meal_plan`, `literature`, `interview`, `customer_support`, `medical_claim` 각 1개를 열어 설명·조건 확인.
- 새 미션에서 '훈련 시작' → Luna 응답 → 변수 3개 열기 → 최종안 입력 → 평가 및 기록 저장을 확인. 이 단계는 실제 API 호출과 사용료가 발생합니다.
- 기능이 정상이어도 25개 문항의 교육적 난이도와 문구는 팀 차원에서 검토해야 합니다.

## 아직 적용하지 않은 것
- LPA 6유형을 활용한 **개인 맞춤 추천 순서**는 적용하지 않았습니다. 팀원이 제공한 LPA JSON에는 사용자 유형 분류 정보는 있으나, 유형별 교육 선호를 입증하는 추천 매핑 정보가 없습니다. 이 규칙은 분석 결과를 받아 다음 단계에서 설계하는 것이 정확합니다.
- 커뮤니티 게시판 및 사전진단 채점 전체 개선도 이번 수정 범위 밖입니다.

## 주의
- 공개된 과제 텍스트는 데이터일 뿐 모델 API 비밀키를 포함하지 않습니다.
- 훈련 UI에서 3개 파생 상황은 Luna가 API로 생성하므로, `fallback_events`는 모델의 장애 복구 시 사용할 수 있는 예비 데이터이지만 현재 화면에서 자동 대체되지 않습니다.
